03 / SECURITY BOUNDARIES
Protection with a defined scope.
Message confidentiality & authenticity
Signed headers bind the sender, recipient, key fingerprints and expiry. GCM authenticates the header and ciphertext. Active replay protection keys on sender, recipient and transaction ID.
Key custody is an integration boundary
The included provider uses software keys. Its signing and decapsulation interface supports an external provider, but no HSM driver or validated hardware integration is included.
Settlement needs its own controls
Bank authorization, wallet signatures, chain IDs, contract addresses, decimals, durable idempotency and ledger atomicity belong to the settlement system. Encrypting an intent does not make a blockchain quantum-resistant.
